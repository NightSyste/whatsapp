# Night System • Discord Engine

Das offizielle Discord-Management & Automatisierungs-Tool von Night System.

## Features
- **Account Übersicht:** Profil, Nitro, Badges, Telefon, 2FA, Erstellungsdatum.
- **Server Management:** Server-Liste, Multi-Select Server verlassen, Stop-Funktion.
- **Freunde & Gruppen:** Übersicht, Multi-Select Freundes-Entfernung mit automatischem Chat-Closing (DMs löschen).
- **Server beitreten:** Automatischer Beitritt über Einladungslinks mit Sicherheitswarnung.
- **Extra:** Bio, Global Name, Username und Server-Tags dynamisch ändern.
- **Exklusiver Bot-Modus:** Blendet alle anderen Tabs aus, enthält Live Rate-Limit Monitor und Multi-Message Sender für Server & DMs.
- **Universal Target Resolver:** Automatische Erkennung von Server-Textkanälen, DM-Kanal IDs und Freund Nutzer-IDs.
- **Cloud Administration & Remote Lock:** Vollständige Verwaltung und Sperrmöglichkeit über https://whatsapp-kadi.onrender.com.
